# Maths Practice — Family Edition

A self-contained offline/online maths practice app for kids covering:

- 🐨 **Felix** (Grades 1–2) — Känguru der Mathematik, 2013–2025
- 🦘 **Écolier** (Grades 3–4) — Känguru der Mathematik, 2009–2025
- 📚 **CBSE Class 3→4** — Maths, Science, English, Social Science
- 📐 **CBSE Class 6→7** — Maths, Science, English, Social Science
- 🔬 **CBSE Class 7→8** — Maths, Science, English, Social Science

## How to use (offline)

Download all 6 HTML files into the same folder and open `index.html`.

## How to use (online via GitHub Pages)

See deployment instructions below.
